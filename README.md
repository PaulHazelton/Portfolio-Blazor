## Running it

### Without Hot Reload

Switching to the project folder, and run `dotnet run`.
You may first need to run `dotnet build`.

### Hot Reload

You can do hot reload by switching to the project folder, and doing `dotnet watch`. It magically starts the project with hot reload working *fast!*
